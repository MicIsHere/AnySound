# Windows PCVR 实机验收

这份清单需要 Windows 10/11 x64、SteamVR、Quest/PICO 串流头显、控制器及 VRChat。勾选前应记录实际设备、串流软件和版本；源码编译通过不等于这些项目已经验证。

## 便携包

- [ ] 在 Windows x64 + JDK 21 执行 `gradlew.bat clean test portableZip launcherZip` 成功。
- [ ] 推送 `stable` 后，GitHub Actions 自动测试、检查两种解压包，并发布包含便携 ZIP、Launcher ZIP 和 SHA-256 校验文件的 Release；`nightly` 推送不发布。
- [ ] 从 Mac 使用 `prepareLauncher -PtargetPlatform=windows-x64` 生成的完整目录，在 Windows Java 21 x64 上运行 `java -jar anysound-launcher.jar --check` 通过，正常启动能显示界面。
- [ ] 将 Mac 版本 Launcher 拿到 Windows 运行时，直接提示原生库平台不匹配，列出缺失 DLL，而非进入 Compose 后崩溃。
- [ ] 将 ZIP 解压到包含中文和空格的目录，`AnySound.exe` 能启动。
- [ ] 从其他工作目录或 SteamVR 启动仍正常；通过 Launcher 加载主程序、Compose 和语音/OpenVR 原生依赖。
- [ ] 缺失主程序或依赖时显示启动错误，`%APPDATA%\AnySound\logs\launch` 中有日志，日志不包含 API Key。
- [ ] 在没有单独安装 Java 的 Windows 电脑启动，界面和原生库加载正常。
- [ ] 不启动 SteamVR 时，仍可打字、选麦克风和离线转写。

## 文字与 OSC

- [ ] VRChat 已启用 OSC，默认 9000 端口下手动发送文字可见。
- [ ] 中文输入法 Enter 选词不发送；完成选词后再次 Enter 才发送。
- [ ] 144 字符边界、中文、emoji、显式换行和长文分段显示正确。
- [ ] 分段间隔符合设置，后一次输入不会穿插到前一句中间。
- [ ] 取消队列后不再出现尚未发出的后续分段。
- [ ] 编辑、录音时的 typing 指示会在停止、取消和退出时清除。

## 麦克风与识别

- [ ] 本地模型下载、SHA-256 校验、导入和重复载入正常。
- [ ] 速度/准确率模式可切换并保存；旧配置默认速度模式。准确率模式能下载或分别导入 Zipformer 与 SenseVoice，错误目录有明确提示。
- [ ] 准确率模式按住时提供字幕预览，松开后显示精校状态，仅发送一次 SenseVoice 最终文字；对比真实麦克风的错字率、最终等待时间与游戏帧率。
- [ ] 准确率模式的首选语言可保存，旧设置默认中文；将“好、对、是”等短句与自动识别对比，检查最终文字。保存其他语言后下一次录音即生效，无需重启或重新下载模型；速度模式和实时预览保持原有中英识别。
- [ ] 用此前出现连串重复字的正常语句对比两种模式，核对最终文字；同时确认真正重复说出的“你好你好”等表达没有被机械删减。
- [ ] 准确率模式在最终识别期间取消、断开或超时后不发送迟到结果；重录时不混入旧音频，精校失败不发送临时文本。
- [ ] 选择头显麦克风与桌面麦克风分别试用，包括 48 kHz / 44.1 kHz 设备。
- [ ] 普通话、英语和中英混合均可产生部分字幕，松开仅发送最终全文。
- [ ] 长句中的自然停顿只更新字幕，不提前发送。
- [ ] 纯静音、突然断开设备、连续重复按键均不误发或卡住。
- [ ] 单次录音超 60 秒会取消并提示。
- [ ] 关闭自动发送后，可在桌面编辑结果、确认一次或取消。
- [ ] 两个清理开关独立有效，数字、网址与正常语气词保持正确。
- [ ] 提供有效百炼密钥后，在线实时字幕与最终发送正常。
- [ ] 百炼密钥错误、网络中断、超时或额度不足会停止本次发送，旧回调不会污染下一次转写。

## SteamVR 与覆盖层

- [ ] `gradlew.bat :test -PgpuOverlaySmoke=true --tests io.anysound.WindowsGpuOverlayTest` 通过，验证真实 Compose → OpenGL 渲染、上下/左右方向及重建。
- [ ] 双显卡电脑上 AnySound 和 SteamVR 使用同一显卡；图形初始化失败时能看到明确错误，桌面文字发送仍可用。
- [ ] 桌面“覆盖层预览 → 演示动画”和头显覆盖层均能完整播放进出场、音量平滑、录音呼吸指示和处理旋转指示，字幕更新时不逐字闪烁。
- [ ] 进场约 0.5 秒、退场约 0.4 秒，完成后等待 3 秒再退场；取消后先显示“已取消”及说明 2 秒再淡出，期间再次按住立即重录，新发送的文字不会被取消提示遮住。
- [ ] 空闲时或消息已全部发送且覆盖层隐藏后按取消，不弹出 UI；重复按取消不会延长或重新弹出旧提示。录音、待确认文字和待发消息仍可正常取消并显示提示。
- [ ] 退场中重新按住或快速切换显隐无闪回、残影或意外隐藏。隐藏后不再持续绘制动画，录音和游戏性能正常。
- [ ] AnySound 出现在 SteamVR 控制器绑定列表中，可编辑并保存四个动作。
- [ ] 分别使用“按下/press”和“长按/long”绑定录音：按住录音时按取消，连接和输入轮询持续正常，取消内容不发送；松开原键后长按提示消失，再次按住可立即重录，无需重新连接。
- [ ] 取消后继续按住原录音键不会自动重录；录音中控制器输入失效会取消当前内容，输入恢复后可重新按住录音。
- [ ] 退出 AnySound 后注册保留；重新启动 SteamVR 和 AnySound 后仍能找到应用与已保存绑定。
- [ ] Windows 用户名和 AnySound 配置目录含中文、空格时，注册、动作清单加载和从 SteamVR 启动 Launcher 正常。
- [ ] 在头显内的 SteamVR「桌面 1」点击 AnySound“VR 按键绑定”，绑定编辑器在 VR 内打开，不弹出桌面浏览器；无需退出 AnySound 或重新连接。
- [ ] 原生绑定入口返回异常时，提示持续保留，连接和覆盖层不被清理；可在头显内手动进入 SteamVR 控制器设置，或重试按钮。
- [ ] 注册失败、进程关联不符或动作清单缺失时显示具体错误，不显示已连接。
- [ ] Quest/PICO 的实际控制器 profile 可绑定；重启后绑定保留。
- [ ] VRChat 保持前台、未打开 SteamVR 仪表盘时，按住键仍能录音，松开结束。
- [ ] AnySound 不切换 VRChat 麦克风开关。
- [ ] 中文、英文字母与 emoji 在覆盖层正确绘制，没有倒置、色偏或异常透明。
- [ ] 头显内标题位于左上方，音量条位于下方并从左向右增长；字形与桌面面板预览一致，没有镜像或旋转。半透明圆角无黑边，短字幕替换长字幕后无残影。
- [ ] 面板跟随头部，位置、距离、大小与不透明度设置生效。
- [ ] 录音音量、实时字幕、待确认状态及分段发送进度清晰可读。
- [ ] 完成后约 3 秒隐藏，错误持续可见，显示/隐藏动作有效。
- [ ] 控制器断开或 SteamVR 退出时停止录音，不发送不完整文本。
- [ ] 重新启动 SteamVR 后可再次连接；退出 AnySound 后无残留覆盖层。
- [ ] 长时间运行时没有持续内存增长，录音与覆盖层没有明显影响游戏帧率。

# AnySound

在 VRChat 中，用打字或语音转文字与其他人交流。AnySound 将消息发送到 ChatBox，并支持 SteamVR 控制器按住说话和 VR 字幕覆盖层。

**AnySound 不会切换 VRChat 的麦克风开关。** 如果只想发送文字，请保持游戏内麦克风静音。

## 开始使用

需要 Windows 10/11 x64 和 VRChat。语音转文字还需要麦克风；在头显中操作和显示字幕需要 SteamVR。

Quest / PICO 需要串流到电脑，并通过 SteamVR 运行 VRChat。目前不支持头显独立版或绕过 SteamVR 的运行方式。不启动 SteamVR 时，仍可使用桌面文字发送和语音转文字。

### 安装与启动

在 [GitHub Releases](https://github.com/MicIsHere/AnySound/releases/latest) 下载最新稳定版。一般选择 `AnySound-<版本>-windows-x64.zip`；文件名带 `-launcher` 的版本需要自行安装 Java。

使用 Windows 便携 ZIP 包时，完整解压后打开 `AnySound\AnySound.exe` 即可，**无需另外安装 Java**。请保留解压后的整个文件夹；本地识别模型在应用内单独下载。

建议放在 `C:\Apps\AnySound` 等英文路径。部分 Windows 区域设置下，中文安装路径可能导致便携包无法启动。

<details>
<summary>如果你拿到的是 Launcher（JAR）版本</summary>

此版本需要安装 **Java 21 x64**。在包含 `anysound-launcher.jar` 的文件夹中打开终端，运行：

```powershell
java -Dfile.encoding=UTF-8 --enable-native-access=ALL-UNNAMED -jar anysound-launcher.jar
```

Launcher 文件夹中的其他文件也需要保留。

</details>

更新时先退出 AnySound，再替换完整的程序文件夹；设置和已下载模型保存在用户配置目录中。

### 先发送一条文字

1. 打开 VRChat，在动作菜单中启用 **Options → OSC → Enabled**。
2. 在 AnySound 的“文字输入”中输入消息。
3. 点击“发送”或按 **Enter**，在游戏内查看 ChatBox。

中文输入法选词时按 Enter 不会发送，完成选词后再按 Enter 即可。默认发送到本机，通常无需修改连接设置。

长文本会自动分段，输入框下方会显示条数；各段默认间隔 3 秒发送，可在设置中调整。底栏中的“已发出”表示 AnySound 已发送数据，是否显示仍需在 VRChat 中确认。

## 语音识别

打开“设置”，先选择麦克风，再选择识别方式。串流时请确认选中了实际使用的头显麦克风。

| 方式 | 适合的使用场景 | 使用前准备 |
| --- | --- | --- |
| 本地 · 速度模式 | 优先响应速度和较低资源占用 | 下载约 190 MiB 模型，之后可离线使用 |
| 本地 · 准确率模式 | 优先识别质量，可接受松开后的额外等待 | 在速度模式模型之外，再下载约 228 MiB 模型 |
| 阿里云百炼 | 使用在线识别服务 | 网络连接、百炼 API Key 和可用服务额度 |

### 本地识别

1. 在设置中选择“本地离线”和所需模式。
2. 点击“下载所需模型”，等待完成后保存设置。已有模型时也可选择对应目录导入。
3. 在主界面按住“按住说话”，开始讲话，松开后等待最终文字发送。

准确率模式会先显示实时字幕，再在松开后重新识别整段录音，因此最终文字可能与预览不同。如果大多数时候说中文，建议将“首选语言”设为 **中文（普通话）**；经常切换语言时可选择“自动识别”。首选语言只影响准确率模式的最终结果。

识别偶尔会出现错字，尤其是昵称、单字和背景噪声较大时。可关闭“松开后自动发送”，先检查或修改文字，再按“确认发送”。单次录音最多 60 秒，较长内容请分次说。

模型下载失败时可重试，或按[手动下载与导入说明（英文）](docs/TECHNICAL.md#offline-models)准备文件。目前只支持指定的两套模型。

### 阿里云百炼

在设置中选择“阿里云百炼”，填写北京地域的 **API Key** 和对应的**业务空间 ID**，然后保存。默认使用 `paraformer-realtime-v2`；服务端点通常保持默认即可。如果账户提供了不同的接入地址，请按百炼控制台配置填写。

在线模式会将录音发送给阿里云，并使用你的服务额度。应用中填写的 API Key 仅保留到本次退出，重新启动后需要再次填写。识别失败时不会发送当前录音的文字，可检查网络和账户配置后重试。

参考：[百炼官方使用指南](https://help.aliyun.com/zh/model-studio/real-time-speech-recognition-user-guide) · [接入配置与环境变量（英文）](docs/TECHNICAL.md#cloud-recognition)

## 在 VR 中使用

### 绑定控制器

1. 启动 SteamVR，连接头显和控制器。
2. 在 AnySound 点击“连接 SteamVR”，再点击“VR 按键绑定”。绑定页面会在**头显内**打开。
3. 在 SteamVR 中选择 **AnySound**，为“按住转文字”选择一个按钮，使用 **按下 / press** 动作。
4. 按住该按钮讲话，松开后发送最终文字。如果关闭了自动发送，还需要使用“确认发送”。

也支持 **长按 / long**：达到 SteamVR 的长按时间后才开始录音。请自行选择与 VRChat 移动、菜单或手势不冲突的按键，程序不会预先占用控制器按钮。

| 可绑定动作 | 用途 |
| --- | --- |
| 按住转文字 | 按住录音，松开结束 |
| 确认发送 | 发送待确认的识别结果 |
| 取消录音和待发消息 | 丢弃当前录音、待确认文字和尚未发出的消息 |
| 显示或隐藏覆盖层 | 切换头显中的字幕面板 |

录音中取消后，请先松开原录音键，再次按住即可重录，无需重新连接。取消无法撤回已经发出的消息；空闲时按取消不会弹出面板。

### 字幕覆盖层

覆盖层显示录音状态、实时字幕、待确认文字和发送进度，完成后自动淡出。待确认内容和错误会持续显示。

在设置中可以调整面板的位置、距离、大小和透明度。主界面的“字幕覆盖层”开关控制显隐，“覆盖层预览”可以在桌面查看效果；点击“演示动画”可查看示例。

## 输出优化

主界面的两个开关默认开启，**只处理语音识别结果**。手动输入以及确认前自行修改的文字保持原样。

- **过滤停顿词**：过滤独立的“嗯”“呃”等停顿词，保留“好啊”“走吧”“你呢”等正常表达。词表可在设置中编辑。
- **清理逗号和句号**：去掉中英文逗号、句号，在句子之间保留空格；保留问号、感叹号及数字、网址中的必要标点。

例如，`嗯，我们走吧。你呢？` 会变成 `我们走吧 你呢？`。

## 常见问题

**点击发送后，游戏里没有文字？** 先确认 VRChat 已开启 OSC，再检查 AnySound 设置中的目标地址和端口。两者在同一台电脑时，默认是 `127.0.0.1:9000`。底栏的发送状态不能确认游戏已经收到消息。

**SteamVR 中找不到 AnySound，或无法打开绑定页面？** 先在主界面连接 SteamVR。更新后请关闭旧版，启动新版并重新连接。也可以在头显内进入 SteamVR → 设置 → 控制器 → 管理控制器绑定，手动选择 AnySound；按实际控制器类型创建绑定。

**语音输入不可用或没有识别结果？** 检查模型是否已下载并保存设置、麦克风是否选对，以及 Windows 是否允许桌面应用使用麦克风。首次录音需要加载模型，可能比后续录音慢。

**中文单字被识别成英文？** 在准确率模式下，将首选语言改为中文并保存，下次录音生效。此设置能减少语言误判，但仍建议检查重要消息。

**加载模型后内存占用明显增加？** 本地模型会保留在内存中，便于下次快速开始。准确率模式同时使用两套模型，占用更高；停止录音后不立即下降属于预期行为。如果希望降低占用，可使用速度模式。

**覆盖层没有显示或连接时出现图形错误？** 确认 VRChat 正通过 SteamVR 运行，并已打开“字幕覆盖层”。双显卡电脑可在 Windows 图形设置中让 AnySound 与 SteamVR 使用同一块独立显卡。

## 隐私与数据

本地识别不上传录音。只有选择在线模式并录音时，音频才会发送到配置的阿里云服务。AnySound 不保存录音文件或聊天历史；界面只保留当前会话的文字。API Key 不写入普通设置和应用日志。

Windows 的设置、下载模型和启动日志位于 `%APPDATA%\AnySound`。启动失败时，可查看其中的 `logs\launch` 文件夹。
